# Olga Dental Clinic

Лендинг стоматологической клиники OLGA Dental Clinic.

## Стек

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

## Возможности

- адаптивная верстка
- светлая и темная тема
- форма записи
- карточки врачей
- отзывы
- карта Яндекса
- мобильная оптимизация

## Запуск

```bash
npm install
npm run dev
