# Функциональная регрессия

Дата: 15.11.2026. Исходная ревизия: `b52dc6849d94baac48c32aa0d35f4e62126f74a2` (`preview/soni-development`). Финальные исходники проверены в ветке `audit/olga-quality-2026` и зафиксированы коммитом `e3d33759be9b383b492f96624172f3f5d8fa5033`; полная матрица и завершающий smoke разделены ниже. Это проверка локальных production static exports, а не работающего Beget.

## Методика и границы

Использован настоящий headless Chromium через Playwright Core 1.65.1 и axe 4.14.0. Полные версии браузера, время и URL записаны в JSON. Основной сервер — `http://127.0.0.1:4173`, обычный preview с выключенной реальной отправкой.

Размеры: **320×568, 390×844, 430×932, 844×390, 768×1024, 1366×768, 1920×1080, 2560×1440**. Обе темы. Это эмуляция размеров; настоящие iPhone и iOS Safari не проверены. Реальные экранная клавиатура и safe-area inset устройства недоступны. Дополнительно проверены поворот viewport и уменьшение его высоты до 390×420.

Для проверки разрешённой серверной ветви формы создан отдельный, неопубликованный экспорт `/tmp/olga-enabled/out`: synthetic consent version и включённая запись. В браузере имитировался production origin, **каждый HTTP-запрос перехватывался**; статические файлы возвращались с диска, API/Метрика — из mocks. Настоящий сервер клиники, реальные заявки и данные пациентов не использовались.

Основной браузерный набор блокирует внешние запросы. Поэтому наличие iframe, его URL и организация переходов проверены, но загрузка самой Яндекс.Карты этим набором не подтверждается. Lighthouse измеряется отдельно, см. [PERFORMANCE.md](PERFORMANCE.md).

`document.scrollWidth` недостаточен для визуального QA: исходные `overflow-hidden` скрывали слишком длинные слова. Поэтому дополнительно использовались реальные скриншоты и DOM Range. В `heading-clipping-*.json` есть имена боковых карточек карусели: их частичное скрытие — предусмотренная композиция, не обрезанный основной текст.

В исходных 28 попытках семь false подтверждали проблемы семантики/фокуса диалогов и Escape мобильного меню. Ещё две попытки открытия drawer на 844/768 не соответствовали исходному breakpoint `md`; зависимые проверки Escape на этих размерах не являются доказательством исправности. В итоговой версии drawer действует до `xl`, и эти размеры проверены реально. Четыре новых сценария drawer → запись довели набор после исправлений до 32.

В первом after-запуске единственный false — устаревшая проверка точной строки «Укажите имя и корректный номер телефона». Теперь форма выдаёт отдельные сообщения об имени и телефоне. [validation-followup-after.json](evidence/validation-followup-after.json) подтверждает четыре фактических alert и отсутствие API-запросов. Первоначальная гипотеза о native validation была опровергнута: у формы `noValidate`; диагностический JSON явно помечен как гипотеза. Тест исправлен под действующее поведение; неудачные промежуточные результаты не скрыты.

## Проверенные сценарии

- Navbar и Hero открывают запись; услуга и врач передаются в контекст формы.
- Все семь профилей врачей открыты и проверены по имени в заголовке. Переход из профиля к записи сохраняет врача. Все семь фильтров дают непустой результат, «Все» восстанавливает семь карточек.
- Реальное нажатие переключателя меняет светлую/тёмную тему; выбор сохраняется после reload. Стрелки карусели меняют активного врача и возвращают предыдущего, Enter открывает профиль. FAQ услуги открывается кликом и закрывается клавишей Enter.
- Видимые labels, клавиатурный Tab внутри диалога, Escape, возврат фокуса и восстановление прокрутки работают.
- Мобильное меню открывается/закрывается, удерживает фокус, переводит в запись. Проверены 320/390/844/768, включая низкий landscape.
- Клик по backdrop закрывает booking, профиль врача и drawer; body scroll разблокируется.
- Форма проверяет имя, телефон и отдельное согласие. Ввод цифр вместо имени отклоняется. Ошибки доступны через `role=alert`.
- Demo ясно сообщает, что заявка не отправлена. Настоящий API из preview не вызывается.
- Mock API: успех, 503, некорректный JSON, сетевой сбой, таймаут 15 с, повтор с тем же UUID, отключённый localStorage, двойное нажатие и закрытие ожидающей формы. Ошибка сохраняет поля и возможность повторить отправку; старый ответ не меняет вновь открытую форму.
- Аналитика не инициируется до разрешения; отказ и повторный выбор работают, в том числе при исключениях Storage. Открытие настроек немедленно выключает отслеживание; hit не содержит query/hash. Поведение самой библиотеки Яндекса за пределами mock этим тестом не оценивается.
- Контактные `tel:` и ссылка организации имеют ожидаемые публичные значения. Копирование адреса в настоящий Clipboard API проверено в Chromium. `mailto:` присутствует на `/privacy/` и `/consent/`; отрендеренный href подтверждён в обеих темах. В отдельном разделе контактов email не выводится. Почтовое приложение и доставка письма не тестировались; сведения не изменялись.
- Три возврата Back, три перехода из акций к якорям, прямой fragment и сохранение пользовательского скролла при задержке JS на 1800 мс подтверждены на финальном экспорте.
- Reflow при эквиваленте 200%: 1366×768 представлен как 683×384 CSS px с DPR 2. Шесть страниц без горизонтального overflow; форма остаётся доступной. Это проверка эквивалентного reflow, не нажатие масштаба в интерфейсе Chrome.
- `prefers-reduced-motion: reduce` действительно включён; CSS animation duration `1e-05s`, действия drawer/формы доступны.

## Что ещё требуется для рабочего запуска

1. Изолированная приёмка на реальной конфигурации Apache/PHP/MySQL Beget с синтетическими данными и проверкой прав, HTTPS, cron/retention, резервного восстановления и сессий. Локальные PHP-проверки описаны в [SECURITY.md](SECURITY.md).
2. Проверка настоящего iOS Safari, устройства с safe-area, экранной клавиатуры, VoiceOver/NVDA и браузерного UI zoom 200%.
3. Проверка доступности Яндекс.Карты и поведения внешних сервисов в целевой сети; финальная юридическая оценка согласий и черновиков документов.
4. Полная браузерная приёмка удалённого Vercel Preview. Выполнена read-only HTTP-выборка: главная, статья и политика — 200 с `X-Robots-Tag: noindex, nofollow, noarchive`; PHP/admin — 403, без раскрытия PHP-исходников. Это не проверка Beget и не удалённый E2E. [Доказательство Vercel Preview](evidence/vercel-preview.json), приложение `e3d3375`, состояние READY; Deployment Protection сохранена.

Отсутствие axe-нарушений в выбранном наборе не означает гарантированного соответствия всем требованиям WCAG 2.2 AA. Успех mock-отправки не означает готовности production API.
